# PASIVE TREE

## PASIVE TREE 1.0.0-beta2 · Addon for ZoneLevelUp

### English

Build a character through 49 connected passive nodes across eight branches. Open the tree from **Races → PASIVE TREE**, press **P**, or use `/pasivetree`. Each character earns one tree point every eight ZoneLevelUp levels, up to five ranks per node and 45 invested points.

Reach the **Master** rank in racial ascension with either of the current character's active races to invest or use passive bonuses. Points accumulate before unlocking. If the character no longer meets the requirement, invested points are retained and their bonuses resume when the requirement is met again.

### Español

Especializa a tu personaje con 49 nodos pasivos conectados en ocho ramas. Abre **Razas → PASIVE TREE**, pulsa **P** o usa `/pasivetree`. Cada personaje gana un punto cada ocho niveles de ZoneLevelUp. Puede invertir hasta cinco rangos por nodo y 45 puntos en total.

Alcanza el rango **Maestro** de Ascensión racial con cualquiera de las razas activas del personaje para invertir puntos y aplicar los bonos. Puedes acumular puntos antes de desbloquear el árbol. Si dejas de cumplir el requisito, las inversiones se conservan y sus bonos vuelven cuando lo cumples.

### Installation / Instalación

Minecraft 1.20.1 · Forge · Java 17. Use the respective **1.0.0-beta2** client and server JARs (TreeNetwork 2) with [ZoneLevelUp](https://www.curseforge.com/minecraft/mc-mods/zonelevelup) **2.0.0-beta29-r87** on both sides. / Instala el JAR beta2 correspondiente en cada lado junto a la pareja r87 de ZoneLevelUp.
